# Безопасный путь — готовый прототип

Это статическое веб-приложение для проекта «Карта комфортных маршрутов для вечерних прогулок».

## Что уже работает
- карта OpenStreetMap;
- поиск адресов;
- определение текущего местоположения;
- построение пеших маршрутов;
- альтернативные варианты, если сервис маршрутизации их возвращает;
- оценка маршрута 0–100;
- пользовательские отметки: плохое освещение, безлюдный участок, хорошее место, магазин/открытое место, остановка;
- сохранение отметок в браузере;
- получение части инфраструктурных данных OpenStreetMap через Overpass API;
- мобильная адаптация.

## Запуск
Просто открыть `index.html` в браузере. Для геолокации и более стабильной работы рекомендуется размещение на GitHub Pages или Cloudflare Pages.

## Используемые внешние сервисы
- OpenStreetMap — карта;
- Nominatim — поиск/обратный поиск адресов;
- OSRM — пешая маршрутизация;
- Overpass API — получение части объектов OpenStreetMap.

## Важное ограничение
Это учебный MVP, а не система, которая гарантирует безопасность человека. Оценка маршрута является ориентировочной и зависит от полноты данных карты и пользовательских отметок.

## Следующий этап
Для полноценного проекта стоит добавить серверную БД (например, Supabase), аккаунты, модерацию пользовательских отметок, историю маршрутов и более строгую модель оценки.
